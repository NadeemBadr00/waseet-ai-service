# بيبو — واجهة متصلة بمنصة وسيط

حركات بيبو تعمل في المتصفح. الأسئلة والصوت تحتاج جلسة مستخدم وسيط وباك المنصة؛ النسخة المحلية المعدّلة لم تُنشر بعد. لا تضع مفاتيح Gemini أو بيانات خدمة وسيط في المتصفح. راجع [دليل الربط](PLATFORM_INTEGRATION.md) لتوصيل جلسة المستخدم.

## التركيب في موقع
انسخ الصور وrobot.js وbebo-chat.js إلى /bebo/ في الموقع، ثم أضف:

```html
<script defer src="/bebo/robot.js"></script>
<script defer src="/bebo/bebo-chat.js"></script>
<cute-robot id="bebo" size="112" floating interactive floor-offset="110" home-x="116"></cute-robot>
<bebo-chat robot="#bebo" api-base="/api/help-assistant"></bebo-chat>
```

الصفحة الكاملة المعروضة في التجربة موجودة في index.html، ومعها preview.css وpreview.js.

الكتابة تظهر تحت الشخصية، والردود قصيرة في السحابة. زر المحادثة يعرض السجل الكامل. الإعدادات تحتوي اللهجة والصوت وطريقة الرد. المايك يحتاج إذن المتصفح ودعم SpeechRecognition؛ للموقع المنشور استخدم HTTPS.

جرّب: ارقص، اضحك، عيط، افتح اللاب، اجري ورا القطة، طلع دبّانة. أوامر الحركة تعمل محليًا؛ نطق التأكيد والردود الذكية تستخدم الخدمة المشتركة.

اللهجات متاحة من الإعدادات، والأصوات والموديلات حسب الإمكانات المفعّلة في الخادم. حدود الطلبات وحالة الخدمة تطبق على الاستخدام. تُرسل رسائلك وسياق آخر المحادثة إلى باك وسيط بجلسة المستخدم؛ الإملاء الصوتي تابع لخدمة المتصفح. السجل محفوظ داخل التبويب حسب المستخدم والدور، ويمكن مسحه أو تصديره.

هذه الملفات واجهة فقط؛ ملفات الخادم والإعدادات السرية ليست ضمن التسليم.

زر النجمة «حركات بيبو» بجانب أيقونات الشات والصوت يفتح 23 خيارًا: الحركات والتعبيرات والتحكم في التجول والصوت. كل اختيارات القائمة تعمل فورًا محليًا، دون استدعاء AI أو TTS أو استهلاك كوتا. معاينات الكلام والاستماع بدون صوت. اختيار حركة يوقف الرد أو التسجيل الجاري؛ Escape أو زر الإغلاق يغلق القائمة.
