========================================================================
  WaseetAI Platform - Frontend Console & Integration Package
========================================================================

مرحباً بك في حزمة واجهة وتكامل منصة وسيط للذكاء الاصطناعي (WaseetAI).
الواجهة مربوطة مسبقاً وبشكل مباشر بالسيرفر السحابي (Cloud Run).

هل تحتاج أي مفاتيح API أو إعدادات سحابية؟
- الإجابة: لا إطلاقاً! لن تحتاج أي مفاتيح أو إعدادات أو تثبيت قواعد بيانات.
- التوكن والربط مع السيرفر السحابي مدمج تلقائياً وجاهز للاستخدام الفوري.

------------------------------------------------------------------------
طرق التشغيل المحلي (Run Locally):
------------------------------------------------------------------------

[الطريقة 1] لمستخدمي ويندوز (الأسهل بنقرة واحدة):
- اضغط دبل كليك على الملف: `RUN_LOCAL.bat`
- سيفتح المتصفح تلقائياً على: http://localhost:3000

[الطريقة 2] عبر VS Code:
- افتح المجلد في VS Code واضغط كليك يمين على `index.html` واختر:
  "Open with Live Server"

[الطريقة 3] عبر سطر الأوامر (Node.js أو Python):
- باستخدام Node:
  npx serve .
- باستخدام Python:
  python -m http.server 3000

[الطريقة 4] فتح النسخة السحابية المباشرة (بدون تشغيل أي سيرفر محلي):
- https://waaseet-ai.web.app
